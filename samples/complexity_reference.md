# Beginner complexity reference

- O(1): roughly constant work.
- O(log N): work grows slowly as N grows, such as binary search.
- O(N): usually one pass through N items.
- O(N log N): common for efficient comparison sorting.
- O(N^2): nested loops over the same list; may be slow for large N.
- O(2^N): all subsets; only practical for small N in many cases.

Always check the problem's input constraints before choosing an algorithm.
